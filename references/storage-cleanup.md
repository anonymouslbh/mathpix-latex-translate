# 翻译工程清理工具

使用技能安装目录下的 `scripts/cleanup_project.py`，只需 Python 标准库。默认先生成清单，实际清理必须使用 `apply`；不得按文件修改时间猜测哪一份是最终版本。

## 保留范围与准备

先读取项目、进度、问题及最终交付记录，确定最新已核验 PDF、对应最新一套页面图、必要问题页和相关历史比较 PDF。原书、最新译文、最终 PDF、可编辑工程、原图与封面资产、日志和验收记录必须保留。工具自动保护项目根下的 `source/`、`baseline/`、`translation/`、`delivery/`、技能和脚本目录，以及 `project.json` 中声明的原始输入；已有工程使用其他目录名时在 `keep` 中明确补充。

清理开始前停止该书的所有写入、编译和渲染进程；只暂停当前聊天不能证明另一聊天也已停止。同一书籍保持单一清理者。没有清理授权时只生成预览；已有明确授权时完成清单核对后执行，不反复请求同一授权。本工具的加入或技能规范修改本身不意味着既有缓存已经清理。

策略 JSON 使用项目内相对路径，不支持通配符。按项目实际状态建立，例如：

```json
{
  "current_pdf": "build/current/main.pdf",
  "current_pages": "qa/latest-pages",
  "keep": [
    "qa/issues",
    "qa/latest-acceptance.json",
    "qa/comparison-baseline/main.pdf"
  ],
  "generated_roots": ["qa", "build"],
  "image_roots": ["qa/stage01/pages", "qa/stage02/pages", "qa/latest-pages"],
  "obsolete_pdfs": ["build/stage01/main.pdf"],
  "duplicate_copies": [
    {"path": "qa/package-staging/project", "keep": "qa/verified-project"}
  ]
}
```

- `current_pdf`、`current_pages`：必须指向真实存在且已核验的最新译稿及完整页面集；工具不代替全页验收，也不会自动选择时间戳最大的文件。
- `keep`：额外保留的目录或文件，包括所有未结问题页、原书校对页、修复前后对照以及仍需支撑验收的历史 PDF。必要校对记录没有统一机器格式，调用者必须依据实际问题清单补全。
- `generated_roots`：明确属于本项目的生成缓存目录，禁止使用项目根或原始、可编辑、最终交付目录。
- `image_roots`：明确只用于派生页面图片或对照图的目录。扫描其中图片，排除最新集、问题页及原图/资产目录；文本、JSON、日志不会作为旧图片删除。
- `obsolete_pdfs`：逐一列出已被替代、无需继续支持比较且可从保留工程重建的 PDF；工具不会批量删除所有 PDF，也不会推断版本是否过期。
- `duplicate_copies`：逐一列出缓存中的待删副本及必须保留的对应文件/目录。两者文件清单和每个文件的 SHA256 必须完全一致；仅名称相似或大小相同的版本拒绝清理。可编辑主工程或最终交付不同于副本时继续保留，不能强行视为重复。

已有目录不必改名；清单中无需清理的类别使用空数组。问题关闭后更新 `keep` 再生成新清单，不修改历史验收结论。

## 预览与执行

从实际加载的技能路径确定脚本位置，工程与输出使用真实绝对路径。例如：

```text
python "<skill安装目录>/scripts/cleanup_project.py" plan "<书籍工程目录>" --policy "<策略文件.json>" --output "<新清理清单.json>"
python "<skill安装目录>/scripts/cleanup_project.py" apply "<书籍工程目录>" --plan "<清理清单.json>" --report "<新清理日志.jsonl>" --writers-stopped
```

`plan` 不删除文件，报告候选文件数、分类和大小。先核对保护清单、候选路径和必要证据是否已纳入；图像只保留最新一套和问题页，PDF 只删除明确过期项，副本只删除逐文件一致项。

`apply` 会永久删除候选清单中的文件。执行前复核项目路径、保护文件、候选文件哈希和大小；文件或当前页面集变化时拒绝执行，须重新生成清单。符号链接、Windows 目录联接、越界路径和重复执行日志均拒绝；不递归删除整个目录，空缓存目录可保留。实际候选文件长度合计不等于精确释放的磁盘空间，硬链接或文件系统压缩会影响后者。

清理日志记录每个文件的路径、哈希、大小、类别以及删除前意图和实际结果。中断后先检查日志和当前文件，重新规划剩余项；不盲目重放旧清单。保留清理清单和日志，历史验收中被删除的图片路径应通过新的清理记录标明可重新渲染，不伪装文件仍存在。

退出码：`0` 为计划生成或清理完成；`2` 为路径、保护规则、文件变化或执行错误。CLI 参数错误也返回 `2`。报告技能新增、候选大小和实际清理结果时分别说明，不把预览当作空间已经释放。
