# 统一目录版式

默认方案 `toc-book-v1`，适用于本用户的整书中文翻译。用户明确模板优先；已有译本在用户要求改版时应用，skill 更新本身不代表旧 PDF 已更新。字体和字号沿用 typography.md，以下全部尺寸为 TeX pt；em 按目录条目的 11pt 计算。

## 页面与标题

- 目录位于封面、必要的扉页/版权页和前言之后，正文第一章之前，从新页开始；保留原书必要前置材料的相对顺序。
- 标题写“目录”，黑体、22pt、基线距30.8pt、居中，不加编号，不拉开字间距。标题段前0pt、段后18pt，以正文版心顶端为基准。
- 目录使用正文同一版心和页边距，不使用表格、边框、彩底或独立装饰。目录续页不重复大标题；页眉使用“目录”，页眉与页码9pt。
- 目录各页使用工程统一的前置部分页码方案；未采用独立前置编号时沿用连续页码。不得因套用目录规范擅自更改已有正文编号。PDF物理页序与印刷页码分别核验。

## 层级和条目

默认收录章、一级节、二级节；三级节及更深层级不收录。article 或自定义宏按真实语义映射，不能只根据命令名称决定层级；没有章的文档从实际最高层级开始。前言、附录和参考文献按其真实位置作为顶层条目收录，存在多个章节参考文献时保留归属，不重复添加不存在的总参考文献。目录不收录自己，也不收录封面、封底、空白页；章作者姓名不单独作为目录条目。

| 语义层级 | 字体与字号 | 左缩进 | 编号盒最小宽度 | 额外段前/段后距 |
| --- | --- | ---: | ---: | ---: |
| 章、顶层前置/后置条目 | 黑体11pt；西文与数字沿用共享字体 | 0em | 3em | 6pt / 3pt |
| 一级节 | 宋体11pt | 1.5em | 3.5em | 0pt / 0pt |
| 二级节 | 宋体11pt | 3em | 4.5em | 0pt / 0pt |

所有条目基线距15.6pt。层级通过字形、缩进和章间留白表达，章条目不直接使用正文章标题22pt。页首第一条不叠加6pt段前距。编号格式保持原书/工程的语义编号（如1、1.2、1.2.3、A），不同时重复“第1章”和“1”。编号盒内左对齐；无编号条目的文字从该层级左缩进处开始。编号较长时统一扩大相应层级的编号盒，在共享配置与项目记录中保存实际值，不能逐条挤压。

## 引导线、页码及换行

- 各层级都使用细点引导线，点间距一致（默认 LaTeX dotsep 4.5mu）；引导线只出现在条目最后一行。文字末尾与页码前各留至少0.5em空隙，不用手工连续输入句点或空格。
- 页码使用共享西文数字字体，11pt、正常字重，全目录右对齐至同一版心右边界。默认页码盒宽3em，文字排版预留右侧4em，较长的罗马数字或特殊页码须统一扩大，避免与标题重叠。
- 长标题在编号后的文字起点悬挂换行，续行不退到编号起点、不落入页码栏；不为塞入一行缩小字号。优先正常中文断行，保留公式与专业含义。
- 同一条目的多行文字不跨页；章条目尽量与其首个子条目同页。自然分页，不压缩行距以减少目录页数。
- 页码须来自实际编译的目录信息，条目与页码均能点击并跳到正确目标；PDF书签层级与真实章节对应。不要用手写页码替代自动目录。

## 接入与验收

在唯一共享 layout.tex 或其加载一次的目录配置文件中实现，并由 project.json 的 toc_profile 与 style-guide.md 记录方案ID、真实层级映射、深度、尺寸、配置路径和例外。优先适配文档类现有接口；检查已有 tocloft、titletoc、ctex 或自定义目录命令，避免重叠接管。不要按章单独设置目录样式，或把同一 tocdepth 数值盲目用于不同类。

试排须包含顶层、两级子条目、无编号前言/参考文献、附录、含公式及至少两行的长标题、多页目录。实际核对字号、15.6pt基线距、悬挂缩进、点线、页码对齐、条目跨页与Unicode提取；默认数字不保证所有标题都能适配，例外须统一调整并记录。

编译至辅助文件收敛后，逐条核对显示页码、实际印刷页码、链接和书签目标，不以编译成功代替。目录改版可能改变后续物理页序或连续页码，须重新编译并复查全书分页、图表和交叉引用。保留实际渲染和验收记录；未执行时只能说明规范已更新，不能声称现有PDF已采用。
